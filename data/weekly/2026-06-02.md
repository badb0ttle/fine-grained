# 本周 AI 大事记 (2026-06-02)

## 🔥 本周头条

MiniMax 在周末投下了一枚重磅炸弹。这家中国 AI 初创公司发布的 M3 大模型，在多项关键基准测试中同时超越了 OpenAI 的 GPT-5.5 和 Google 的 Gemini 3.1 Pro，而推理成本仅为前两者的 5-10%。这不是渐进式改进，而是一次性价比的范式转移。M3 配备了 100 万 token 上下文窗口和原生多模态能力，月费仅 $20——这一价格策略直接挑战了当前企业 AI 市场的定价体系。如果说 2025 年是「谁的模型最强」，2026 年的叙事正在变成「谁能在不破产的情况下提供最强模型」。

与此同时，企业 AI 基础设施的军备竞赛持续升级。Alphabet 宣布计划融资 800 亿美元用于 AI 基础设施建设，理由是「需求远超现有供给」。NVIDIA 则联手微软、戴尔和惠普推出 AI Agent PC，试图将 AI Agent 从开发者工具变成大众消费品，正式切入价值 2000 亿美元的 CPU 市场。

## 📊 趋势观察

**LLM 评测体系正在经历一场信任危机和重建。** 本周出现了多篇引人深思的论文：NumLeak 揭示了公开数值基准测试可能已作为「隐式标签」泄露到基础模型训练数据中，这意味着我们在用「泄题」后的试卷评价模型。另一篇论文引入 Item Response Theory（项目反应理论，IRT）来审计 LLM 基准测试，试图用量化方法区分模型的「真实能力」和「应试技巧」。结合 Anthropic 提交 IPO 申请和 OpenAI 模型登陆 AWS 的商业化浪潮，评测体系的可靠性从未如此重要——当数十亿美元的投资决策依赖这些数字时，「作弊」不再只是学术问题。

**Agent 正从概念走向工程化。** SAGE 论文提出了一种新颖的记忆进化门控机制，让 Agent LLM 能在不遗忘的前提下高效更新内部知识——这解决了长期困扰 Agent 系统的「记忆腐烂」问题。而 Intel 与至强 6+ 的案例则从硬件维度展示了 Agent 规模化部署的可能：一颗 288 核 CPU 同时运行 500 个 Agent。模型能力 + 记忆机制 + 硬件支撑，Agent 的三块拼图正在快速就位。

**Benchmark 作为产品正在兴起。** 本周出现了大量新基准：EHRBench（临床决策）、CanLegalRAGBench（加拿大法律 RAG）、BilliardPhys-Bench（物理推理与视觉动力学）。评测不再是研究论文的附录，而是逐渐成为一种独立的研究产出。这种趋势的背面是碎片化风险——当每个细分领域都自建基准时，跨领域比较将变得更加困难。

## 🏷️ 一句话总结

2026 年 6 月的 AI 行业正在从「模型军备竞赛」转向「成本效率 + 评测可信度」的双轨竞争。
