本周 AI 大事记 (2026-06-14)

本周头条

小米 MiMo Code 开源，正面挑战 Claude Code。 本周 VentureBeat 报道，小米 MiMo AI 团队开源了终端原生编程助手 MiMo Code V0.1.0，在 200+ 步的超长 agentic coding 任务上超越 Anthropic 的 Claude Code。这不是又一款 IDE 插件，而是直接运行在终端的自主编程 Agent，支持跨文件重构、多步规划。这是国产开源 AI 编程工具首次在复杂任务上声称领先，意味着代码智能体赛道的竞争已经从「跟跑对标」进入「正面硬刚」阶段。

Agent 工具调用研究集中爆发。 本周有三项重磅研究同时指向 LLM Agent 最头疼的问题——工具调用。ToolSense 框架诊断出当前基于 embedding 的工具检索存在系统性缺陷：模型对大量工具的用途理解严重不足，失效根因不在推理而在检索。另一项研究提出基于不确定性对齐的强化学习方案，专门解决 Agent 的「幻觉式直接回答」和「无效工具调用」，让 AI Agent 在复杂多步任务中更靠谱。还有 MacArena 基准在真实 macOS 桌面上对 Computer Use Agent 进行全面评测，覆盖 GUI 操作、视觉理解和多步任务规划——Agent 评测正在从玩具沙盒走向真实操作系统的战场。

趋势观察

AI 安全从原则走向工程化部署。 MLUBench 提出面向多模态 LLM 的「终身遗忘」评估基准，直接对接 GDPR 等隐私法规对数据删除权的刚性需求——模型遗忘能力正在从学术概念变为合规硬指标。另一项工作聚焦临床 LLM 的查询级拒绝风险评估，在医疗这个容错率几乎为零的场景里，「会不会拒绝回答」本身就是一种安全能力。更底层地，一篇大规模调研揭示了人类对 AI 偏好的高度多样性——不同人群对 helpfulness、honesty、harmlessness 的优先级差异显著，RLHF 追求的「平均偏好」可能本身就是错的。多元对齐策略不再是可选项。

小模型在专业场景找到生存空间。 一篇研究表明，小型 LLM 在生物医学声明验证任务上通过低成本微调和结构化数据策略，效果可以逼近 GPT-4o——医疗 AI 落地不必非得拿大炮打蚊子。开源 DPO 全面实证研究给出了覆盖模型规模、数据配比、超参选择的调优手册，让中小团队也能把偏好对齐做到位。在 Diffusion LLM 这个新架构方向上，FAIR-Calib 解决了量化压缩时的稳定性滞后问题，打开了这类新型模型部署空间的可能。

AI4Science 的务实转向。 跨尺度基准评测系统检验了现有 AI Agent 在从分子到社会的真实科研挑战中的能力边界——结论不是「AI 能搞科研了」，而是「离真正做科研还有不少差距」。这不是冷水，是方向标：知道瓶颈在哪，比喊口号有用得多。

一句话总结

本周关键词：Agent 工具调用、开源编程 Agent 争霸、以及安全合规从「要不要做」变成「怎么做」——AI 行业正在从模型能力竞赛转向工程可靠性竞赛。
